🔥 今日剛啟動（單日淨流入明顯放大，且過去非持續堆積）
判定：今日淨流入(張) ≥ 自身近20日均值 3 倍以上，且方向為買超，過去20日尚未列「堆著」。收盤後資料，最快隔日才能進場，抓到的是啟動後第2天起，非當日即時訊號；產業歷史未滿10個交易日前不列入判斷。
淨流入（紅） 淨流出（綠） 持續性條：越長＝錢越單向堆積，越短＝進進出出互相抵銷
指標定義：產業每日淨流入(張) = Σ(外資買賣超股數 + 投信買賣超股數)/1000，樣本內成員加總（不含自營商）； 產業每日淨流入(金額估) = Σ(個股淨股數 × 個股當日收盤價)，只加總「當天股數與收盤價都有」的股票， 是估算值不是三大法人實際成交金額。可切換今日／近一週（5日）／近一月（20日）三種累積區間； 持續性 = |Σ每日淨流入| / Σ|每日淨流入|，介於0~1，越接近1代表錢每天都同方向、持續堆積， 越接近0代表進進出出、互相抵銷（今日單日無此概念，不計算）。
評語門檻：持續性 ≥0.6 = 堆著；0.25–0.6 = 混合；<0.25 = 只是經過（本站自訂粗略門檻，非逆向工程任何第三方網站的演算法）。
資料來源：TWSE T86（上市三大法人買賣超彙總表）＋ MI_INDEX（上市收盤行情）、 TPEx open API（上櫃三大法人買賣明細、上櫃收盤行情），涵蓋全市場上市＋上櫃個股； 產業分類為 FinMind TaiwanStockInfo 官方 industry_category（分類本身不常變動，不需每日重抓）。
侷限：樣本數低的產業（標示較淡）統計雜訊較大；上櫃股票的歷史趨勢因官方 API 無歷史查詢， 採「切換當天起逐日累積」，近一週／近一月數據會在切換後約20個交易日內逐步補齊到全市場水準。
這是描述已發生的資金流向，不是預測，也不構成買賣建議。
